# 💧 AquaQuiz — Apple Water Glassmorphism MCQ Practice & Quiz App

A mobile-first, Apple-inspired **Water Glassmorphism** MCQ practice and quiz web application for **Conservation Geography (NPTEL / University Syllabus)**, covering all 12 weeks (120 verified MCQs) with week-wise filtering and comprehensive all-in-one mode.

🌐 **Live GitHub Pages URL**: [https://imyashwanthsdp.github.io/conservation-geography-mcq/](https://imyashwanthsdp.github.io/conservation-geography-mcq/)

---

## ✨ Features

- 💧 **Apple Water Glassmorphism Aesthetics**:
  - Deep fluid liquid canvas with floating ambient gradient refraction orbs.
  - Specular frosted glass panels (`backdrop-filter: blur(28px) saturate(200%)`).
  - Specular highlight rim borders (`1px solid rgba(255, 255, 255, 0.18)`), inner sheen, and subtle light reflections.
  - Spring micro-animations and water droplet audio feedback synthesized with Web Audio API.

- ⚡ **Practice Mode (Instant Answer Reveal)**:
  - Instant visual feedback on every option tap:
    - **Correct**: Emerald water flash with checkmark pop.
    - **Incorrect**: Rose water pulse on chosen option with automatic reveal of the correct answer.
  - Zero explanation clutter — focused on rapid retention.

- 📝 **Quiz Mode (Real Exam Simulation)**:
  - Live timer tracking.
  - Lock-in and switch options freely before submission.
  - Bottom sheet quick-jump question grid with color-coded status.
  - Liquid glass celebration results card with animated SVG score gauge.
  - Comprehensive question-by-question review of user answers vs correct solutions.

- 📅 **Scope Selection**:
  - **All Weeks Mode**: Practice all 120 questions across the entire curriculum.
  - **Week-Wise Mode**: Filter by individual week (Weeks 1 to 12) with full topic titles.
  - **Random Shuffle**: Shuffle questions to test memory and prevent order bias.

- 📱 **Mobile-First Experience**:
  - Thumb-friendly bottom dock navigation bar.
  - Safe-area support for iOS home indicator and notch/Dynamic Island.
  - Responsive down to 320px width up to 4K displays.
  - Fully offline-ready zero-dependency static web application.
